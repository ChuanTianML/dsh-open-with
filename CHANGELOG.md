# Changelog

## 0.2.0 — 2026-08-23

- Add a compact Open split button to the current Session Header while retaining the Workspace-menu entry.
- Add `openWith/refresh` and shared browser state so editor discovery updates every mounted launcher without restarting DSH.
- Add Windows App Paths and bounded JetBrains Toolbox discovery.
- Add VS Code Insiders, Trae, VSCodium, GoLand, CLion, Rider, PhpStorm, RubyMine, DataGrip, RustRover, Android Studio, and Sublime Text profiles.
- Keep the first Windows editor window visible and remove Host credential variables from the launched process environment.

## 0.1.1 — 2026-08-14

- Publish the multi-editor Workspace launcher and compatibility menu adapter.
